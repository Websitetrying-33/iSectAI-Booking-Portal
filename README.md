# iSectAI Client Management & Booking Portal (CRM v2.0)

A responsive full-stack web application and booking portal built for service professionals and medical practices to manage client appointments, schedules, and workflow tracking.

## 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS, FontAwesome, Google Fonts (Plus Jakarta Sans)
* **Backend:** Node.js, Express.js
* **Database:** SQLite (Relational local storage with complete CRUD support)

---

## 🚀 Features
* **Interactive Dashboard:** Real-time metrics overview, data counts, and connection indicators.
* **Appointment Management:** Create, view, update (Edit), and delete bookings with custom status badges (Confirmed, Pending, Completed, Cancelled).
* **Client Notes & Metadata:** Attach special requests and client notes directly to records.
* **Data Export:** Built-in CSV export tool for spreadsheet reporting.
* **Responsive Dark SaaS UI:** Modern aesthetic optimized for desktop and mobile screens.
